# زيتون — Olive Agent

تطبيق ويب لإدارة وتصميم البيوت البلاستيكية، مع أدوات لرسم مخطط البيت وتحديد الأبواب والأقواس ومناطق شتلات الزيتون.

## الروابط

- **التطبيق:** [olive-agent.netlify.app](https://olive-agent.netlify.app/)
- **مستودع GitHub:** [OctopusOkhtobot/Zetton](https://github.com/OctopusOkhtobot/Zetton)

## طريقة الاستخدام

1. افتح [التطبيق](https://olive-agent.netlify.app/) في المتصفح، ثم أدخل اسمك للبدء.
2. اختر **بيت بلاستيكي جديد**، ثم اسحب على مساحة الرسم لتحديد مستطيل البيت.
3. اتبع الأدوات بالترتيب لإضافة الأبواب والأقواس، ثم ارسم مناطق الشتلات وأدخل الصنف والتاريخ وعدد النباتات.
4. استخدم أدوات التحكم لتعديل التصميم ومراجعته. يمكنك اختيار البيت من القائمة لتحديده أو متابعة العمل عليه.
5. تُحفظ بيانات البيوت تلقائياً في تخزين المتصفح على الجهاز نفسه. استخدم خيار **حفظ كصورة / تصدير المخطط** لتنزيل صورة للمخطط ومشاركتها.

> **ملاحظة:** البيانات محفوظة محلياً في المتصفح؛ قد لا تظهر عند استخدام جهاز أو متصفح آخر، وقد تُحذف إذا مُسحت بيانات الموقع. احتفظ بنسخة من المخططات المهمة عبر تصديرها كصور.

## أبرز الميزات

- تصميم وإدارة أكثر من بيت بلاستيكي.
- رسم حدود البيت وإضافة الأبواب والأقواس.
- تخطيط مناطق شتلات الزيتون وتسجيل الصنف والتاريخ والعدد.
- أدوات تكبير وتحريك وعرض تفاصيل المخطط.
- استخدام مناسب للهواتف والحواسيب، مع إمكانية تثبيت التطبيق من المتصفح كـ PWA.
